## 什么是 ContextCore？

ContextCore 是一款虚幻引擎编辑器插件，可将蓝图资产导出为 AI 可读的文本格式，使 AI 编程助手（ChatGPT、Claude、Gemini 等）能够理解您项目中的可视化逻辑，并提供精准的辅助。

### 核心差异

- **Lite** 仅导出**所选的蓝图本身** — 每次只能导出单个资产，不进行依赖扫描。
- **完整版**执行**深度依赖分析**，自动导出父类、组件、接口以及所有引用的资产，为 AI 提供项目的完整上下文。
- **完整版**包含**实时自动同步**：初始化后，被追踪的资产在保存或编译时会自动重新导出 — 您的 AI 上下文永远不会过时。
- **完整版**在蓝图之外还支持 **14 种资产类型**，包括材质、MetaSound、数据表、C++ 类等。

## 安装

1. 将 `ContextCoreLite` 文件夹复制到项目的 `Plugins` 目录下
2. 重启虚幻编辑器
3. 插件将自动加载（仅编辑器插件）

## 使用方法

1. 在内容浏览器中，右键点击任意蓝图资产
2. 选择 **Export to Context (Lite)**
3. 导出文件将保存至 `[项目目录]/Docs/.context/`

## 输出结构

```
Docs/.context/
└── [资产路径]/
    ├── _meta.json           # 元数据（类信息、组件、函数）
    ├── EventGraph.txt       # 主事件图表
    ├── Function_*.txt       # 函数图表
    ├── Macro_*.txt          # 宏图表
    └── StateMachine_*.txt   # 动画蓝图状态机
```

## 系统要求

- 虚幻引擎 5.5+
- 仅编辑器使用（不随打包构建分发）
